# 笔记整理模板（观过章案例）

> 适用场景：用户要求对某章做"笔记整理"——这是介于注疏汇编和公众号文章之间的中间产物。
> 它不是文章，是后续写文章的依据。结构上以学术梳理为主，包含老丁因子（个人观点）。
>
> 触发信号：用户说"笔记整理""笔记整理情况""整理一下这一章的笔记""梳理一下参考资料和注疏分歧"。
>
> 与 anlects-review 的区别：不跑完整的七阶段流水线——不做逐家六维解剖、不开圆桌、不搞横纵分析。直接从已有 docx 注疏汇编中提取材料，按以下七段结构编排。

## 七段结构

### 一、原文
原文 + 一字面译。简洁即可，不需要展开训诂。

### 二、典籍来源清单
分三类列出本章涉及的所有文献：

1. **经部互证**：其他经典中与本章互证的段落（如《礼记》《左传》等），引用原文并翻译
2. **史部案例**：史书中引用本章的案例（如《汉书》《后汉书》引观过知仁判案）
3. **注疏著作**：用表格列出每家注疏（时代+著作+在本章中的角色/核心论点）

### 三、注疏分歧（逐条分析）
找出本章的核心分歧点，每条一个表格或对比段落。典型分歧类型：
- 关键词释义分歧（如"党"=类 vs "党"=亲比）
- 版本异文分歧（如"人"vs"民"、"仁"vs"人"）
- 逻辑路线分歧（如观者知仁 vs 过者之仁）
- 历史案例适用性争议

### 四、注疏盲区与疏漏
找出注疏传统集体忽略或处理不当的维度。这是老丁最有价值的部分——不是复述注疏，而是指出他们没看到什么。典型盲区类型：
- 内在逻辑矛盾（如孔注既说"非其过"又说"恕"）
- 过度扩展（如焦循把八个字读成完整行政考核法）
- 时代错置（如宋儒埋没殷仲堪首创权）
- 分类盲区（不同类型"过"被混为一谈）
- 未被追问的前提（如"观过"的主体默认是外部观察者）
- 制度风险（理论被反向利用的可能性）
- 被忽视的优秀读法（如刘开"亲比"说被边缘化）

### 五、老丁因子——个人观点
- **核心判断**：一句话（须违背或深于常见理解，但可被文本与逻辑支撑）
- **证据链**：[实证]级证据，逐条对应
- **论证路径**：完整推理，每步可追溯
- **与主流差异**：表格对比
- **潜在反例**：预判质疑并给出回应
- **定位说明**：哪些是[实证]，哪些是[推论]，证据不足处标注[待挖掘]

### 六、写作锚点
为后续公众号文章准备的素材库：
- ⭐⭐⭐ 入戏开头素材
- 比喻型素材
- 冷知识锚点
- 留白收尾素材

### 七、核心论点链预排
后续文章的大致段落结构预排，用编号格式（1. 2. 3. ...）。

## 格式要求
- 用 markdown，保存到 `笔记/` 目录，命名 `{章节号} {章名简称}_笔记整理.md`
- 字号不做要求，但每段要有明确标题
- 引用原文必须翻译，一行不省
- 涉及陌生人物加朝代+身份
- 不确定的推断标注[推论]

## 与公众号文章的关系
笔记整理是"原料仓"。后续写公众号文章时，从笔记整理中提取：
- 开头素材 → 从"写作锚点 > 入戏开头"中选
- 注疏分歧段 → 从"分歧分析"中挑最有张力的1-2个
- 老丁读法 → 从"老丁因子"中取核心判断
- 冷知识 → 从"盲区"中挑最反直觉的
- 结语 → 从"写作锚点 > 留白收尾"中选

公众号文章的字数限制（~2500字）意味着不可能放进全部八条分歧和八个盲区——笔记整理的价值就在于先做完整梳理，再从中精选最锐利的部分写入文章。
