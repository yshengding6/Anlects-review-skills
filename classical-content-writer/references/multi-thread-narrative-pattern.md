# 多线合一叙事模式

> **触发条件**：多角度方案提案后，用户选择「组合」而非单选时启用。
> **首次成功案例**：6.17生直章（A焦虑史+C搭便车为主线，B概率论+D马郑分歧为冷知识辅线，四线合一）。

## 模式结构

```
主线A（情感驱动） + 主线C（观点锚点） = 文章主干
辅线B + 辅线D = 冷知识穿插（每条约150-200字，用「这里有个冷知识得展开说一下」换挡）
```

## 各线功能

| 线 | 角色 | 落点 | 示例（6.17） |
|----|------|------|-------------|
| **主线A** | 情感叙事引擎 | 文章推进的动力——历代注疏家的反例焦虑 | 马融→包咸→李充→程颐→朱熹→毛西河→张岱，每一代防御升级 |
| **主线C** | 最终观点锚点 | 结语的核心判断 | 钱穆：罔者活着是因为直者在替他维持社会 |
| **辅线B** | 冷知识① | 中途插入，用「冷知识得展开说一下」换挡 | 概率论：孔子说的是常态描述，不是因果保证 |
| **辅线D** | 冷知识② | 靠近开头插入，提供叙事骨架 | 马融vs郑玄：「生」=善终 vs 「生」=始生，一个字的歧义炸出两条路线 |

## 节奏控制

1. **开头**：日常场景入戏 → 原文呈现 → 辅线D（马郑分歧）做叙事骨架
2. **中段**：主线A推进（汉代→宋代→明代），按时间线层层升级
3. **冷知识换挡**：辅助线B插入，「这里有个冷知识得展开说一下」
4. **转折**：主线A到达低谷（张岱的绝望）→ 主线C（钱穆）作为解药登场
5. **结语**：主线C展开 → 回扣开头 → 意象收束

## 判断标准

- 四线是否互相支撑而非互相打架？主线A+C的论点是否一致？
- 辅线B/D是否在各自位置提供了「新知」而非重复主线？
- 冷知识插入点是否刚好在读者需要喘息的地方（连续3段以上考据/论述后）？
