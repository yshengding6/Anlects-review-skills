# 笔记整理——前置输出类型

> 适用场景：用户要求"笔记整理""梳理注疏情况"而非直接写公众号文章时。这是介于 anlects-review 分析层与 public article 写作层之间的中间产出——学术内部文档，供后续文章直接引用。

## 触发信号

- "笔记整理"
- "整理情况"
- "梳理一下……参考了哪些典籍"
- "分析注疏分歧和疏漏"
- "笔记才作为正式解读的依据"

## 与完整写作递进流程的区别

| | 笔记整理 | 标准公众号文章 |
|---|---|---|
| 读者 | 自己（研究参考） | 公众号读者 |
| 风格 | 结构化、可查证、允许方括号标记 | 文学散文、自然过渡、禁用方括号 |
| 字数 | 无限制（通常1-3万字） | 2500字左右 |
| 流程 | 直接出完整文档 | 哲学转译→提纲→示范→初稿→定稿 |
| 格式 | 七章结构（见下） | 自然段落 |

## 七章结构

### 一、原文
原文 + 字面译。一行都不省。

### 二、典籍来源清单
分三层：
1. **经部互证**：同书其他章、《礼记》《左传》等先秦典籍的平行文本
2. **史部案例**：注疏中引用的历史典故（《汉书》《后汉书》《南史》等）
3. **注疏著作**：按时代排列表——注疏家、朝代、著作、在本章的角色

### 三、分歧分析
逐条列出注疏分歧，每条含分歧点描述 + 各立场对比表 + 分析。

典型分歧类型：
- 关键词释义分歧（"党"=类 vs 亲比）
- 版本分歧（"人"vs"民"、"仁"vs"人"）
- 解释路线分歧（"观者知仁"vs"过者之仁"）
- 历史案例适用性争议

### 四、盲区与疏漏
这是笔记整理的核心价值所在——注疏们都在说什么，以及更重要的是：他们都没说什么。

编号列出，每条含：
- 盲区描述
- 为什么它是盲区
- 可能的分析方向

类型示例：
- 逻辑矛盾（孔注"非其过"+"恕"自相矛盾）
- 过度扩展（焦循将八字扩展为完整行政方法）
- 学术史不公正（宋儒埋没殷仲堪）
- 分类缺失（五种"过"未做区分）
- 提问方向缺失（"观过"的主体从未被追问）
- 制度风险被低判（燕王旦案例的理论滥用）

### 五、老丁因子
核心原创判断 + 五段结构：

1. **核心判断**：一句话说破——违背常见理解但可被文本支撑
2. **证据链**：逐条[实证]级证据
3. **论证路径**：步骤1→2→3→结论
4. **与主流差异**：表格对比老丁读法 vs 注疏传统
5. **预判反例与回应**：列出可能的质疑并给出文本回应

### 六、写作锚点
直接可用的文章素材：
- ⭐⭐⭐ 入戏开头素材
- 比喻型素材
- 冷知识锚点
- 留白收尾素材

### 七、核心论点链预排
未来文章的段落到段落结构预览（不写正文，只写"这一段讲什么"）

## 材料来源

仅使用用户提供的注疏材料（通常是程树德《论语集释》+ 刘宝楠《论语正义》两个docx）。材料中出现的典籍引文可以追溯但不自行检索外部来源。

## 保存规则

- 保存到 `笔记/` 目录，命名 `X.Y 篇名·章简称_笔记整理.md`
- 推送 Get笔记（如已配置），完整正文、非摘要
- 此文档是后续公众号文章的直接参考来源
