# 人物中心多成语文章写作模式

> 适用场景：围绕一个历史人物展开、涉及多个成语（3-5个）的专题文章
> 与"成语语义下坠"模式的区别：不追踪单个词语义的演变，而是追踪一个人物与多个成语之间的复杂关系
> 来源：匡衡与四个成语文章（2026-06-10）

---

## 与成语语义下坠模式的核心差异

| 维度 | 成语语义下坠 | 人物中心多成语 |
|------|------------|-------------|
| 主轴 | 词的语义演变 | 人的命运弧线 |
| 成语数量 | 2个主词 | 3-5个，围绕同一人物 |
| 结构 | 词A→词B→共同逻辑 | 励志面→政治面→反面→共同逻辑 |
| 核心张力 | 词为什么坏了 | 词没坏，人坏了 / 同一人身上正反两面并存 |
| 史料来源 | 各词出处各自标注 | **强制优先正史**（汉书/资治通鉴），野史（西京杂记等）须标注性质 |

---

## 结构模板

```
1. 开头：从一个最著名的成语（通常是励志面）切入
   - 这句成语每个人都会背
   - 一句转折：教科书没讲这个人后来做了什么
   - 不展开，制造悬念

2. 励志面：成语A + 成语B（2-3段）
   - 成语A：出处、原文、白话翻译、正史/野史性质标注
   - 成语B：出处、原文、白话翻译
   - 正史底色：《史记》《汉书》中对这个人真实起点的记载
   - 上升弧线：从底层到最高位的关键节点

3. 政治面：成语C（1-2段）
   - 此人在政治/学术辩论中引用的经典语句（如《公羊传》引文）
   - 他在最高位时的政见、改革、上疏
   - 这个面的成语可能是"引用者"而非"出处"——标注清楚

4. 反面：成语D + 历史事实（3-4段）
   - 贪墨/打压/投机的具体操作（来自《汉书》原文）
   - 弹劾措辞（引用原文+白话翻译）
   - 与石显/陈汤等关键人物的关系
   - 最终结局（免为庶人等）

5. 共同逻辑（1-2段）
   - 对比励志面和反面的同一个意象（如"穿墙"）
   - 对比同一张嘴在不同时期的语言
   - 不是评价，是呈现——让读者自己感受断裂

6. 结语（2-3段）
   - 回到开头那个成语的画面
   - 用具体形象收束，不总结不说教
   - 字数控制在2400-2600
```

## 关键写作规则

### 史料来源标注（强制）

**【强制】每个成语/典故必须标注原始出处及史料性质：**

- 《汉书》《史记》《资治通鉴》→ 正史，可直接引用
- 《西京杂记》→ **必须标注"野史/小说性质，正史不载"**
- 《公羊传》等经典 → 标注经典名+篇名，区分"出处"与"引用者"

标注格式示例：
- ✓ "《汉书·匡张孔马传》载：'诸儒为之语曰：无说《诗》，匡鼎来；匡说《诗》，解人颐。'"
- ✓ "《西京杂记》（东晋葛洪编，野史性质，正史不载）中出现了完整故事"
- ✓ "《公羊传·文公九年》的原文是……匡衡与贡禹在讨论夷狄政策时引用了这句话（见《汉书》）"

### 正史优先原则

当正史记载与野史/民间传说冲突时：
- 先引正史的简洁记载
- 再提野史版本，标注"性质存疑"
- 不因野史故事更精彩而喧宾夺主

### 人物弧线

- 不回避矛盾：同一个人可以同时是励志典范和反面教材
- 不分拆人格：不写"他变了"，写"同一个动作、同一张嘴、不同的对象"
- 意象对照优先于道德判断：如"穿墙取光→穿墙取地"比"他堕落了"更有力

### 成语处理

- 主词3-4个最优。5个以上冲淡深度
- 每个成语必须有：出处原文+白话翻译+史料性质
- 区分"成语的出处"和"此人的引用"——不一而足出自《公羊传》，匡衡是引用者

### 正反平衡

- 励志面约占35-40%
- 政治面约占15-20%
- 反面约占30-35%
- 共同逻辑+结语约占10-15%
- 不刻意追求"对半开"，让史料本身的重量决定篇幅

## 已知文章案例

- 2026-06-10: 匡衡与四个成语（凿壁偷光、匡鼎解颐、不一而足、专地盗土/监守自盗）
  - 史料来源：《史记·张丞相列传》《汉书·匡张孔马传》《资治通鉴》《西京杂记》《公羊传·文公九年》
  - 结构：励志面(凿壁偷光+解颐)→政治面(不一而足)→反面(专地盗土+打压陈汤+石显)→共同逻辑(同一堵墙)→结语
  - 用户要求：励志+反面并重，补充不一而足等成语，正史来源标注
