# 成语变迁/语义演变类文章写作模式

> 适用场景：独立成语演变专题文章（非《论语》章句分析）
> 来源：6.2 佞+弹冠相庆两词文章；牛衣对泣单词文章

## 子类型判断（前置·新增）

成语演变文章分两种子类型，动手前先判断：

| 子类型 | 核心问题 | 案例 | 模板 |
|--------|---------|------|------|
| **贬义化** | 词从什么时候开始变坏？谁/哪篇第一次贬义使用？ | 佞、弹冠相庆 | 模板A：双词对照（现代义→古义→节点→分析）×2 + 共同逻辑段 |
| **降格/扁平化** | 原典的丰富性是怎么被磨掉的？哪一层被删了？ | 牛衣对泣 | 模板B：单词深挖（原典还原→后世引用轨迹→为什么某一层被系统忽略） |

**判断标准**：如果核心论点是"原典有X，后世只剩Y"，走模板B。如果核心论点是"原典是中性/正面，后来变坏了"，走模板A。

**动手前先搜 Get笔记**：成语类话题往往已有 pre-written 语义分析笔记，搜到的材料决定最终走A还是B。

## 语义演变类型判断（前置，影响全文结构）

成语的语义演变分两种路线，写作前先判断属于哪一种——结构完全不同：

| 类型 | 机制 | 代表词 | 核心问题 | 单/双词 |
|------|------|--------|---------|---------|
| **贬义化** | 词义从正面/中性跌为负面 | 佞、弹冠相庆、爪牙 | "谁、哪篇、什么时候把词变坏了" | 双词对照最优 |
| **降格/扁平化** | 原典中的复杂角色被简化、戏剧张力被抹平 | 牛衣对泣、故剑情深 | "什么时候开始人们不再读原典，按自己的想象重写了故事" | 单词深挖最优 |

**降格/扁平化案例的核心特征**：
- 原典中有一个鲜明的人物形象（如牛衣对泣中骂醒丈夫的刚烈妻子、故剑情深中主动寻旧剑的汉宣帝）
- 后世简化了这个形象——把"妻子怒喝丈夫"改写为"夫妻抱头痛哭"，把"帝王主动求旧"改写为"弃妇求而不得"
- 关键证据：成语的字面描述（"对泣"）在原典中根本不存在——这是后人脑补的
- 来自 Get笔记 的 "成语误用三例" 笔记将此分类为 **"人物形象降格"**——区别于 七月流火（字面意义翻转）、美轮美奂（适用范围泛化）、不赞一词（核心语义转移）

**判断方法**：问自己"这个词变坏了吗？"——如果答案是"没有变坏，是被简化了"，则走降格/扁平化路线。

## 结构模板

### 模板A：贬义化双词对照（佞+弹冠相庆型）

```
1. 开头：从现代人的直觉感受切入
   - 场景快闪：今天用这个词是什么感觉
   - 一笔带过其他同类词（做"不止一个词在跌"的证据）
   - 转折：翻开古籍，这些词全不是这个意思
   - 【推荐】使用用户的个人发现叙事

2. 词A：现代义 → 古义（引用原文） → 谁/哪篇/什么时候 → 为什么变了
   2.1 现代义：场景式写法
   2.2 古义：引用原典原文，展开原文含义，引完立刻大白话翻译
   2.3 贬义化节点：【强制】必须回答"从什么时候开始、谁、哪篇文章"。
       能确定到具体篇目就写「北宋苏洵《管仲论》」，追不到就诚实写「已不可考」。
   2.4 为什么变了：历史因素→政治因素→道德因素，按时间节点推进

3. 词B：同上四段结构

4. 共同逻辑段
   - 引用其他同类词做旁证（爪牙、明哲保身等，各引一句诗经原文即可）
   - 分类：能力型下坠 vs 自保型下坠（用自然语言，不要A类B类标签）

5. 结语：2-3段，用具体画面收束
```

### 模板B：降格/扁平化单词语深挖（牛衣对泣型）

```
1. 开头：从成语的字面谎言切入
   - 先展示现代用法（"成语词典说这是夫妻共守贫贱"）
   - 立刻戳破：原典中根本没有"对泣"——妻子在骂人，不是陪哭
   - 一句话钩子："这个成语连名字都是错的。"

2. 原典还原（最核心的段落，占全文40%）
   - 逐句引用《汉书》原文，展开故事全貌
   - 重点放大被后世抹掉的人物细节：妻子的怒喝原话、语气、丈夫的反应
   - 交代完整故事弧线：穷书生哭→妻子骂醒→后来官至京兆尹→想弹劾权臣→妻子再次劝阻→他不听→死在狱中
   - 妻子出现了两次，两次都是清醒的声音——这才是原典中的她

3. 降格节点
   - 什么时候开始，人们把"妻子怒喝"改写成了"夫妻对泣"？
   - 后世诗词用例追踪：司马光"客卧牛衣忧死别"（只剩下凄凉，没了刚烈）→ 苏轼"身后牛衣愧老妻"（只剩愧疚，没了怒喝）→ 李晓愚称之为"首都爱情故事"
   - 关键转折：当"牛衣中涕泣时耶"（妻子后来的原话）被断章取义——人们只记住"涕泣"，忘了说这话的人是什么语气

4. 为什么被降格
   - 一个骂丈夫"何鄙也"的女人，不符合后世对"贤妻"的想象
   - 温柔陪哭比怒喝骂醒更容易被记忆——文化偏好过滤了不舒适的原典
   - 可以提一句同类降格词做旁证（故剑情深：汉宣帝主动求→弃妇求而不得）

5. 结语：2-3段
   - 回到原典的最后一个画面（妻子说"人当知足，独不念牛衣中涕泣时耶"——这句话比任何后世改写都有力量）
   - 不说教，不总结
```

## 关键写作规则

### AI叙事模式陷阱（写作前必读）

**【强制】初稿完成后对照 [anti-ai-narrative-patterns.md](anti-ai-narrative-patterns.md) 自查。** 成语演变类文章最常见的五种AI味：
1. 预告式反转开头（"只有一个问题——翻开原文，根本不是这么回事"）→ 改：直接入戏
2. 设问式过渡（"从X变成Y，中间发生了什么？"）→ 改：直接进入下一段
3. 元叙事点评（"这才是完整故事""故事还没完"）→ 改：删除
4. "不是X，是Y"句式泛滥 → 改：多样判断句
5. 诗词引用段变成编年体文献综述（"五代X写...到了宋代Y写...明代Z写..."）→ 改：每个诗人换一种出场方式，给场景和上下文

本次牛衣对泣初稿五类全犯，重写后全部清除。

### 词数控制
- 2个主词最优。3个开始冲淡，5个一定是流水账
- **铁律**：用户说「写五个成语的变迁」时，必须主动建议缩减到2个。「五词各300字」和「两词各700字」，后者能扎出深度
- 旁证词（爪牙/明哲保身等）只在共同逻辑段一笔带过，各引一句原文即可，不展开训诂和演变

### 引用规则
- 每词必须引用原始出处原文（《诗经》《论语》《汉书》《左传》等）
- 引完立刻用大白话翻译，一行都别省
- 古义段落的核心任务：让读者感受到原典里的正面/中性含义
- **⚠️ 二次材料传递陷阱**：Get笔记/分析文件中的概括性引用（如「苏轼写弹冠已带讽刺」）不是核验终点。这类没有具体篇目出处的判断，必须在写进文章前追溯到原始文献——追不到就删掉人名改为时代模糊表述，或直接删除。铁律：文章中出现的每个具体人名+具体行为判断，作者必须能回答「出自哪本书哪一篇」。

### 现代义段落
- 用场景感而非词典释义：「你说他是佞臣——对方会觉得你在骂他」
- 不要写成「佞，现代汉语意为花言巧语谄媚人」这种词典体

### 演变段落
- 按时间节点推进：先秦→汉代→唐宋→明清
- 每个节点一句话说清"什么变了"
- 不展开制度史细节（如察举制的具体操作），只保留与词义直接相关的因果

### 共同逻辑段
- 不要写成学术分类报告
- "两条路不同，交汇在同一个点上"比"A类B类C类"更自然
- 旁证词的原典引用可以压缩到半句（「予王之爪牙」），不需要完整训释

## 已知文章案例

- 2026-06-15: 牛衣对泣 单词深挖（本模板 B 来源）
  - 类型: 降格/扁平化（人物形象降格）
  - 材料来源: Get笔记6条笔记（含语义分析、诗词汇总、发芽笔记）
  - 核心发现: "对泣"在《汉书》原典中根本不存在——当时哭的只有王章，妻子在怒喝"何鄙也"
  - 降格路径: 刚烈女性怒喝 → 夫妻抱头痛哭 → "首都爱情故事"
  - 妻子在故事中出现了两次：第一次骂醒哭泣的丈夫，第二次劝阻丈夫不要弹劾权臣——两次都是清醒的声音
  - 关键证据: 熊逸明确指出"严格来说，'牛衣对泣'所谓'对泣'并不存在"
  - 后世诗词用例: 司马光"客卧牛衣忧死别"、苏轼"身后牛衣愧老妻"、顾贞观"泪痕莫滴牛衣透"——全都丢了妻子的刚烈

- 2026-06-02: 佞 + 弹冠相庆 两词文章（本模板 A 来源）
  - 旁证词: 爪牙、明哲保身
  - 材料来源: Get笔记六维解剖 + 框架修正笔记
  - 结构: 开头(个人发现叙事: 学佞美章+听熊逸+翻汉书) → 佞(现代义→古义→节点→分析) → 弹冠相庆(现代义→古义→节点→分析) → 共同逻辑 → 结语
  - 验证成果: 
    * 弹冠相庆贬义化节点已确认——北宋苏洵《管仲论》「一日无仲，则三子者可以弹冠而相庆矣」。竖刁/易牙/开方三人是先秦反面教材，苏洵第一次将此词用于小人身上
    * 佞的贬义化节点：汉代孔安国注「佞，口才也」已是功能主义解读；朱熹《论语集注》引程子「佞人，鲜矣仁」在「口才」和「仁」之间画防火墙，彻底定案
  - 验证教训: 初稿中「苏轼写弹冠已带讽刺」无法追溯到具体篇目，删掉换为「宋代党争语境中『弹冠』已经不可能干净」。用具体人名时必须能回答「出自哪本书哪一篇」
