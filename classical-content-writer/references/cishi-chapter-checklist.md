# 辞仕章写作清单（弟子拒仕/辞官类章节）

> 适用于：弟子被征召/任命而拒绝的章节（如6.7费宰章、5.2子贱章等）
> 强制：以下要素必须覆盖，不可遗漏

## 一、人物身份（开头必含）

- [ ] 该弟子的姓名、字、国籍、少孔子年数
- [ ] 孔门四科归属（德行/言语/政事/文学）
- [ ] 在《论语》中出现次数和出场风格
- [ ] 孔子对该弟子的评价（引用原文）

## 二、关键词展开（必须在分析段前独立展开）

- [ ] **职位名称**：制度性含义（家宰vs邑宰、中枢vs外镇），引用制度文献（如贾公彦《仪礼疏》）
- [ ] **地理关键词**（如"汶上"）：地理志出处（如《汉书·地理志》），政治管辖权含义（如齐鲁边界），后世文化语码（如"汶上=辞仕避世"）
- [ ] **动词辨析**（如"辞"vs"拒"）：原注训诂，语用含义差异
- [ ] **关键人物**（如南蒯、公山弗扰）：身份+行为+出处，每人1-2句话简介

## 三、旁证材料（必须检索）

- [ ] **《孔子家语》**：是否记载该弟子曾出任该职？如有，提出时间线推论（如"堕三都期间代理"）
- [ ] **"要绖从政"类证据**（如毛奇龄引）：证明该弟子并非一概不仕
- [ ] **其他弟子同仕对比**：列出同门仕同一势力者的完整清单，逐一标注职位类型
- [ ] **后世诗词/石刻**：唐宋以降是否有咏此章的诗词？如有，引用原文；如无，如实告知并解释原因（如"孝道故事更容易入诗，政治拒绝很难押韵"）

## 四、解释框架

- [ ] **三层叠加**（不可单因归因）：制度位置→政治算计→个人判断
- [ ] **帝制线异议**：对康熙/日讲类"公私之辨"的帝制叙事必须提出异议——指出"公私之辨"是帝制概念，春秋家国边界不同，且孔子本人也仕同一势力，此框架无法容纳
- [ ] **孔子本人仕同一势力的处理**：不可跳过，必须放进同一框架

## 五、禁忌

- [ ] **沉默不能作为主干**：即使原文未给理由，也要分析其行为信号（"善为之辞"是策略，"必在汶上"是边界），将"价值判断"而非"沉默"作为论述主干
- [ ] **不可将辞仕等同于不仕**：弟子可能做过其他职位（引用"要绖从政"等），辞的是这个具体岗位
- [ ] **注疏引用必须带著作名**：不说"康熙说"，说"康熙在《日讲》里写"
