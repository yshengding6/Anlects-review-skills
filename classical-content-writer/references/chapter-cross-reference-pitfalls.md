# 《论语》章节交叉校验陷阱

## 已知陷阱 1：雍也篇 6.2 ≠ 仲弓问举贤

### 错误表述
「雍也篇6.2，仲弓问『焉知贤才而举之』」

### 实际情况
- **雍也篇 6.2**：仲弓问子桑伯子。子曰：「可也简。」仲弓曰：「居敬而行简，以临其民，不亦可乎？居简而行简，无乃大简乎？」子曰：「雍之言然。」
- **子路篇 13.2**：仲弓为季氏宰，问政。子曰：「先有司，赦小过，举贤才。」曰：「焉知贤才而举之？」子曰：「举尔所知；尔所不知，人其舍诸？」

### 关联
两章在「仲弓作为掌权者 / 选人者」这个主题上可以互参，但不能写成同篇连续章节。骍角章（雍也6.4）与举贤章（子路13.2）是跨篇呼应，需明确标注。

### 来源
此陷阱出现在 anlects-review v6.1.0 的 6.4 骍角章阶段2分析文件中，随后被传播到初稿。于 2026-05-10 写作定稿阶段被用户指出并修正。

## 通用校验步骤

1. 任何带章节编号的引用（X篇Y.Z），至少扫一眼标准《论语》文本的该位置
2. 如果分析文件说「X篇Y.Z 的内容是…」，写文章前必须验证
3. 跨篇关联必须标注为跨篇关联
4. 不确定时查 学而→为政→八佾→里仁→公冶长→雍也→述而→泰伯→子罕→乡党→先进→颜渊→子路→宪问→卫灵公→季氏→阳货→微子→子张→尧曰 的标准顺序
