# 原典校验：注疏引文的可靠性验证

## 触发条件

当注疏家引用外部文献（如《左传》《史记》《韩非子》等）作为论证支撑时，若该引文对本章解释方向有决定性影响，须回溯原典进行三重校验。

## 校验四步法

### 1. 原文还原

查找注疏家所引文献在传世版本中的完整段落，确认：
- 引文是否准确（字词是否与传世本一致）
- 引文是否完整（前后文是否被截断）

### 2. 标准注疏检索（新增·高优先级）

**【强制】当引文来自有标准注疏系统的文献（《左传》→杜预注、《诗经》→毛传郑笺、《尚书》→孔传、《史记》→三家注等）时，必须同步检索该文献的标准注疏。** 标准注疏中的身份标注（如杜预注「王犯，吴大夫」）、制度解释、叙事功能说明等，可能包含注疏家选择性忽略的关键信息。

- 常见标准注疏对：左传→杜预注/孔颖达疏、诗经→毛传/郑笺、尚书→伪孔传/孔颖达疏、史记→裴骃集解/司马贞索隐/张守节正义、周礼→郑玄注/贾公彦疏
- 检索方法：在引文段落的传世本中，查找紧接引文的标准注疏文字
- 注疏家不引标准注疏本身不构成错误——但若标准注疏中包含与注疏家论证方向相反的信息，该遗漏即为立场假设的分析对象

### 3. 语境还原

将引文放回原文献的叙事语境中：
- 该段落在原文献中承担什么叙事功能？
- 引文前后文是否改变了引文孤立阅读时的含义？
- 注疏家是否选择性引用了部分而忽略了可能削弱其论证的其他部分？

### 4. 论证强度重估

基于原典完整语境（含标准注疏），重估该引文对注疏家论证的支撑强度：
- 原语境与注疏家的使用方向是否一致？
- 原语境是否提供了注疏家未使用但对本章解读有价值的信息？

## 典型案例：赵佑引《左传·哀公八年》

### 赵佑的引用方式

赵佑《温故录》引「王犯尝为之宰，子羽之父好焉」，用以证明：
- 澹台家族「世负民望」→ 子游「乐开府待之」
- 澹台灭明「非公事不见邑宰」是有特权者的主动拒绝

### 原典完整语境

《左传·哀公八年》完整段落：

> 三月，吴伐我，子泄率，故道险，从武城。初，武城人或有因于吴竟田焉，拘鄫人之沤菅者，曰：「何故使吾水滋？」及吴师至，拘者道之，以伐武城，克之。王犯尝为之宰，澹台子羽之父好焉。国人惧。

### 赵佑遗漏的关键信息

1. **叙事语境**：此句出现在「吴军攻克武城」之后、「鲁国国人恐惧」之前
2. **王犯身份**：杜预注「王犯，吴大夫。奔鲁为武城宰」——一个从吴国流亡到鲁国的前吴国大夫
3. **「国人惧」的叙事功能**：武城被克本身不是大患（边邑），「国人惧」的原因是王犯（前武城宰、吴国人）与澹台家族的关系意味着可能存在内应

### 对赵佑论证的双重影响

| 赵佑的使用方向 | 原典的额外信息 |
|-------------|-------------|
| 澹台家族与邑宰有交往传统 | 此传统发生在「通吴嫌疑」的阴影下 |
| 子游会「乐开府待之」 | 若子游知道王犯条，他对澹台家族的态度可能受此历史影响 |
| 灭明拒绝私谒 = 方正 | 灭明拒绝私谒 = 有污点嫌疑家族出身的子弟刻意用极端自律洗刷家族历史 |

### 校验结论

赵佑引文**准确**（传世本一致），但引文**不完整**（切断了战争/通敌/恐惧的上下文）。原典完整语境不仅不削弱赵佑的「社会网络重建」结论，反而为其增加了一个注疏传统普遍忽略的维度——澹台家族与吴国的历史性暧昧关系，可能构成理解灭明「行不由径」的另一把钥匙。

## 通用原则

1. 凡注疏家引用外部文献，标注「[需原典校验]」
2. 外证文献的引用语境与原文语境的方向一致性，须明确标注为「一致/反向/无关联」
3. 注疏家的选择性引用（截取有利部分忽略不利部分）本身就是分析对象——属于六维解剖中「立场假设」维度
