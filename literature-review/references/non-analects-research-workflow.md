# 非《论语》古典文本通用研究流程

> 适用：《易经》《道德经》《庄子》《孟子》（非章句分析时）等无注疏政治史维度的古典文本。
> 对应版本：anlects-review v6.7.0+

---

## 触发规则

当用户提出研究某古典文本，且该文本**不是《论语》章句**时，**不得加载 anlects-review skill**。
anlects-review 的四把手术刀（政治史探针/辞仕深探/年代校验等）均以《论语》的春秋政治语境为设计前提，对其他文本不适用。

## 通用四步流程

### 第一步：材料搜集

加载 `web-research` skill，使用百度百科 + 百度搜索抓取以下内容：

1. **原文全文**：卦辞/爻辞/经文 + 关键传注（如《十翼》《王弼注》等）
2. **学术史脉络**：历代核心注疏节点（汉/魏/唐/宋/清/近现代）
3. **核心争议**：该文本在学术史上最根本的解释分歧
4. **相关百科**：关键词条（如"元亨利贞"）的百科页面

技术路径：`web-research` skill 中的 `fetch_baike()` 模式，逐关键词抓取后清洗 HTML → 正则提取相关段落。

### 第二步：材料汇编

将搜集结果整理为结构化材料文档，包含：

- **原文 + 译文**
- **传注原文**（彖传、象传、文言传等）
- **注疏传统核心节点**（按时代列表，每人一句话核心命题）
- **核心学术争议**（至少有两条不可合并的解释路径）
- **可选切入角度**（3-5个，每个一句话）

保存为 `.md` 文件。这是后续分析的底本。

### 第三步：选角度

展示材料汇编后，**暂停等待用户选择切入角度**。不要自行决定分析方向。

典型角度示例（以乾卦为例）：
- 元亨利贞——四德说与占卜说的断裂
- 龙象与天象——从农事历法到道德隐喻的转化
- 用九的"无首"政治学
- 九三的临界焦虑

### 第四步：深度分析

用户选定角度后，进入深度分析。此时不套用 anlects-review 的七步流水线，但可以借用其中可迁移的工具：

- **可借用**：异常检测（赘词/矛盾词/沉默区）、变量替换实验、模型竞争构建
- **不可借用**：政治史探针、辞仕深探、年代校验（人物年龄推算）、注疏六维解剖中的"时代动机"维度（仅在春秋政治语境下有意义）

分析输出格式保持 anlects-review 的风格约束：
- 结构拆解，非顺滑解释
- 至少两种竞争性解释模型
- [实证]/[推论]/[缺失] 标注

## 案例：乾卦研究（2026-05-24）

用户输入："我想研究易经的乾卦"

执行路径：
1. 加载 web-research skill
2. 抓取百度百科"乾卦"+"元亨利贞"+"彖传"（共3个词条）
3. 提取：卦辞爻辞原文、《彖传》《象传》《文言传》核心段落、王弼→程颐→朱熹→高亨/李镜池注疏脉络、苍龙七宿星象说
4. 编译为材料汇编（6457字符），含四个可选切入角度
5. 展示汇编，等待用户选角度

结果：材料汇编保存至用户桌面，用户尚未选定切入角度。
