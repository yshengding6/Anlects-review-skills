# 轴心分歧框架（Axial Divergence Framework）

## 何时使用

当阶段2面对跨越多个时代的注疏材料，且存在**一对早期注家的根本性分歧**可作为全部分析的组织轴心时，启用此框架。与纵轴谱系法互补——纵轴按时间分层，轴心法则按**张力关系**组织。

## 触发条件

1. 材料中包含≥2家汉代注疏，且二者对核心字词有**不可调和的分歧**
2. 该分歧不是训诂层面的文字差异，而是**哲学基础的不同选择**（行为域 vs 本体域、经验 vs 先天）
3. 后世注疏可以清晰地归入其中一路，或表现为综合两路的企图

典型触发对：马融vs郑玄（「直」的行为正义 vs 性善论）、孔安国vs包咸、何晏vs皇侃等。

## 四层结构

### 层1：八扇门分类

不按时间排列注家，而是按**对轴心分歧的回应方式**分类：

| 门类 | 定义 | 判定标准 |
|------|------|---------|
| ① A路线（原发立场A） | 继承/强化分歧中A方的路线 | 核心训诂词与A一致，推演方向一致 |
| ② B路线（原发立场B） | 继承/强化分歧中B方的路线 | 核心训诂词与B一致，推演方向一致 |
| ③ B路线的升级版 | 用新概念（如「理」替「性」）升级B路线 | 操作路径清晰可追溯 |
| ④ 第三条路 | 完全跳出A/B框架，自辟蹊径 | 不用A或B的核心训诂词 |
| ⑤ 反方（考证工具反击） | 用训诂/考据工具攻击B路线 | 动机为反理学/反宋学 |
| ⑥ 综合调和 | 试图用一个高阶概念统一A和B | 新概念需同时满足A和B的核心关切 |
| ⑦ 官学口径 | 不参与学术争论，程序化复述正统 | 无个人学术立场 |
| ⑧ 现代转译 | 用现代学术范式重新表述问题 | 范式跃迁（个人→社会、道德→制度） |

### 层2：时间轴——分歧如何逐代展开

按时间顺序追踪每一代注疏家对轴心分歧的**操作**：

- 不是「某注家说了什么」
- 而是「某注家对马郑分歧做了什么」——他是选边、升级、综合、还是绕开？
- 每层标注**哲学动机**（为什么这个时代需要这个操作）

格式：`层N（朝代）：注家——操作类型——哲学动机`

### 层3：分歧链——从根源分裂派生出的子裂痕

追踪轴心分歧如何在后续注疏中裂变为多条子分歧线：

```
裂痕1：核心概念的所属域（行为 vs 本体）
裂痕2：关键字的层数/义项（一个义位 vs 两个义位）
裂痕3：反义词的语义（行为判断 vs 性质判断）
裂痕4：条件的对象（物理后果 vs 存在论后果）
裂痕5：解释策略（训诂 vs 义理）
裂痕6：报应论/常态论强度
```

每条裂痕用表格呈现两端代表注家。

### 层4：盲区检测（按学派分组）

不逐家检测盲区，而是**按八扇门分组**检测每个门类的集体盲区：

- A路线的共同盲区
- B路线的共同盲区
- 第三条路的盲区
- 综合方案的盲区
- 现代转译的盲区

## 立场生成机制表

回答「注家为什么选这条路」——将注疏立场与其时代语境关联：

| 注家 | 选择路径 | 生成原因 |
|------|---------|---------|
| ... | ... | 制度约束/历史事件/学术范式 |

关键原则：不是分析注家的「个人偏好」，而是分析他们所处的**学术制度**（科举考什么、疏不破注的约束力）、**历史事件**（党锢、明亡、文字狱）、和**学术范式**（汉学训诂、宋学义理、清学考据、现代社会学）如何限制和塑造了他们的选择。

## 编纂者材料分类分析（如材料含编纂者）

当材料遍历清单中包含「集释者/编纂者」（如程树德《论语集释》）时，追加此模块：

- **板块结构分析**：编纂者用什么板块组织材料（考异/音读/集解/唐以前古注/集注/馀论/发明）？板块顺序透露什么优先级？
- **材料取舍**：哪些注家被收入？哪些被排斥？排斥的理由是什么？
- **按语立场**：编纂者自己的按语站哪边？用编纂之名做判决了吗？
- **板块定性**：「馀论」和「发明」的区别是什么？反方材料被放在哪个板块？

## 与纵轴谱系法的区别

| 维度 | 纵轴五级法 | 轴心分歧法 |
|------|----------|-----------|
| 组织原则 | 按时代分层 | 按对早期分歧的回应方式分类 |
| 优势 | 概念漂移可见 | 分歧逻辑清晰，注疏间对话关系强 |
| 劣势 | 可能淡化跨时代的对话 | 对无早期分歧的章句不适用 |
| 适用 | 概念有语义漂移的章句 | 有≥2家早期注家且存在不可调和分歧的章句 |

## 与六维解剖的关系

轴心法不替代逐家六维解剖——六维解剖仍是每个独立注家的基础分析单元。轴心法提供的是**组织框架**：不是按时间顺序逐一解剖，而是按「该注家对轴心分歧做了什么操作」来组织解剖顺序和叙事。

## 典型案例

6.17 生直章：马融（「直」=行为正义，经验命题）vs 郑玄（「直」=始生之性，本体命题）→ 程颐用「理」替「性」升级郑玄 → 朱子锁定正统 → 张岱开辟心体/禅学第三条路 → 清儒以马融反程颐 → 刘宝楠以「诚」综合 → 钱穆社会学转译。完整案例见桌面文件 `6.17生直章_阶段2_六维解剖.md`。
