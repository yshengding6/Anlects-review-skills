# 异文交叉核验：用户多源材料中的文本分歧

## 触发条件

当用户先后提供同一段注疏原文的不同版本时（如先发唐熙根引述版、后发《论语正义》原典扫描版），必须执行异文交叉核验。

## 典型案例：刘宝楠「子游/子羽独奉而行之」

### 异文

| 来源 | 原文 |
|------|------|
| 用户首次提供的唐熙根材料引述 | 「子羽独奉而行之，以为先王之道存焉」 |
| 用户后续提供的《论语正义》P229原典 | 「子游独奉而行之，以为先王之道存焉」 |

### 两条读法的阐释路径

**读法A：子羽独奉（唐熙根版）**

- 澹台灭明是「独奉而行之」的主体——普通士人在法律失效后独自遵守
- 全章主旨是「得人」——子游发现了一个了不起的人
- 道德来源：个人对先王之道的信仰

**读法B：子游独奉（原典版）**

- 子游是「独奉而行之」的主体——邑宰在其他官员都放弃执行古法时独自在武城执法
- 澹台灭明的「行不由径」是子游治理的结果而非个人道德选择
- 全章主旨是「为政」——子游用古法治理武城

### 处理规则

1. **原典优先**：以用户最后提供/直接标注来源的版本为基准
2. **异文必须标注**：在解剖中明确写出「你的唐熙根材料引作X，但原典作Y」
3. **两条路径都展开**：不选边——完整展开两条读法的阐释路径、政治叙事方向和道德主体判断
4. **异文本身是分析对象**：谁做了这个改动，为什么——如果是唐熙根引述错误，其引述体例需要检讨；如果是有意改动，其动机需要分析

## 通用原则

1. 用户先后提供多个版本的同一段注疏时，标注「[异文交叉核验]」并逐一对比
2. 以原典（非二手引述）为基准版本
3. 异文出现时，在维度五（隐含前提）中专辟一节分析两条阐释路径的差异
4. 核验完成后不需要用户裁决——保留两条路径的完整分析
