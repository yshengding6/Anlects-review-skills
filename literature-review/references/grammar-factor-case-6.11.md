# 语法结构因子案例：6.11 为儒章

## 触发信号

- 「儒」字《论语》全书仅1见（106次君子、24次小人——唯独儒只有1次）
- 注疏家四家进路（何晏/皇侃/朱熹/刘宝楠）全部将此章读作「儒门内部的两类人」，无人追问语法差异

## 发现过程

### 1. 穷举全书同类用法

全书106次「君子」「小人」出场（6.11除外），语法全为陈述句：
- 「君子喻于义」「小人喻于利」（描述已存在的事物）
- 「君子坦荡荡」「小人长戚戚」（描述已存在的事物）
- 「小人哉，樊须也」（描述已存在的事物）

### 2. 定位本章差异

6.11：「女为君子儒，无为小人儒。」

- 主词不是「君子」「小人」，是「儒」
- 句式是祈使句（「女为……无为……」），不是陈述句
- 「为」是及物动词（「做成」），不是系词（「成为/是」）

### 3. 注疏时代错位检验

四家注疏无一例外将本章读作描述语：
- 何晏：「君子为儒，将以明道；小人为儒，则矜其名」——在「儒」门内做分类
- 皇侃：「君子儒以道为身，小人儒以儒为业」——同上
- 朱熹：「为己/为人」——同上
- 刘宝楠：「识大/务卑近」——同上

错位原因：注疏家读《论语》时，「儒」已定型为学派专名——他们只能在已经存在的行当内部做分类。但孔子说这话时，行当还没有门。

### 4. 因子提炼

**核心判断**：6.11是整部《论语》中，孔子唯一一次不是在评价已有之物，而是在为一个尚未定型的东西预置方向。那句话的本质不是描述，是立法。

**证据链**（全部[实证]级）：
1. 「儒」全书仅1见 → 该词在孔子时代远未定型
2. 其余106次君子/小人用法全部为陈述句 → 6.11祈使句是孤例
3. 「为」做「做成」（及物动词）而非「成为」（系词） → 孔子不是让子夏成为什么，是让他制造一个方向
4. 注疏家全部将此句读作描述语 → 注疏传统存在系统性语法盲区

**与主流解释的分歧点**：
- 非对「君子儒/小人儒」的含义提出新解（那是内容层）
- 而是指出整句话的语法被所有注疏家误读了（这是结构层）
- 结构层错误比内容层更根本——它意味着两千年来对这句话的讨论都基于一个错误前提：「儒」已经定型了

### 5. 动词性验证

「为」在「女为君子儒」中：
- 前置宾语结构「女为X」→ 祈使句
- 后接名词「君子儒」→ 及物动词，义为「做成/制造」
- 对比「君子喻于义」：「喻」为不及物动词 + 介词「于」→ 陈述句
- 语法的不可互换性：把「女为君子儒」改成「君子儒者，喻于义也」→ 语义崩塌

## 方法的可迁移性

此方法的核心不是「儒」字的特殊含义，而是**语法结构差异**：
1. 找该词在全书中所有出现 → 分类语法结构
2. 定位本章是否孤立 → 如果是，追问「注疏家为什么没注意到」
3. 最常见的解释：时代错位——概念在后世定型后，注疏家自然地将它读回当时语境

可迁移场景：任何在《论语》中仅出现一次、且语法结构与其他出现不同（或注疏家普遍读成同一种语法）的关键词/句式。
