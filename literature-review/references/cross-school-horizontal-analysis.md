# 跨学派横轴分析法

> anlects-review 阶段4三轴之一——将本章核心概念追踪到孟子、荀子、佛学（及其他学派）中的对应形态，观察概念的蜕变/删除/置换链。

## 触发条件

阶段2六维解剖完成后自动触发。若章句关键词（如「直」「命」「仁」「幸」）在孟荀中有明确对应论述，必须展开。若章句纯属礼制考据无哲学概念，标注「[跨学派横轴不适用]」。

## 操作方法

### 1. 锁定关键词

从本章提取1-2个核心概念。优先选：
- 注疏分歧最大的词（如「直」）
- 全书出现频率低但本章为核心定位的词（如「幸」全书仅约3见，6.17是其中之一）
- 后世学派争议最大的概念

### 2. 制作对照表（五维度）

| 维度 | 孔子（本章） | 孟子 | 荀子 | 佛学 |
|------|-----------|------|------|------|
| 人的初始状态 | 什么 | 什么 | 什么 | 什么 |
| 「X」的来源 | 什么 | 什么 | 什么 | 什么 |
| 「非X」的来源 | 什么 | 什么 | 什么 | 什么 |
| 报应/担保机制 | 什么 | 什么 | 什么 | 什么 |
| 核心关键词的存废 | 什么 | 什么 | 什么 | 什么 |

### 3. 追踪「衰退/置换」链

核心操作：观察孔子的某个关键词在后世如何被处理——

```
孔子：关键词 = 核心判断
  │
  ▼
孟子：关键词 = 边缘词（被某概念消解/替代）
  │
  ▼
荀子：关键词 = 删除（被某制度替代）
  │
  ▼
佛学：关键词 = 不需要（被三世因果/轮回覆盖）
```

每条箭头标注「消解/替代机制」。

### 4. 绘制汇流图

用ASCII图展示四条路径的分叉与合流，标注每条路径的「走向」（如孟子→宋明理学、荀子→韩非法家、佛学→民间信仰）。

### 5. 交叉收敛线

将三轴（横轴/纵轴/跨学派横轴）发现汇合为2-3条最终判断。每条判断必须同时引用三轴证据。

## 6.17 生直章完整案例

### 关键词锁定
- 主关键词：「直」→ 跨学派追踪
- 次关键词：「幸」→ 衰退/置换追踪

### 五维度对照表

| 维度 | 孔子 6.17 | 孟子（告子上/公孙丑上） | 荀子（性恶/劝学） | 佛学（三世因果） |
|------|---------|---------------------|-----------------|----------------|
| 人的初始状态 | 人之生也直（直是初始值） | 性善——仁义礼智非由外铄，我固有之 | 性恶——生而好利、疾恶、纵欲 | 无始无明——业力驱动轮回 |
| 「直」的来源 | 没说（留下空白） | 天生四端→扩充为直 | 礼仪教化矫正弯曲本性 | 正见/八正道→直心是道场 |
| 「罔/不直」的来源 | 没说（留下空白） | 放其心而不知求——丢了 | 天生——人之性就是自私的 | 无明/贪嗔痴 |
| 报应/担保 | 无——「幸」=概率论 | 弱报应论——天将降大任/君子无幸 | 无——用刑替代报应 | 强必然论——三世因果不差分毫 |
| 「幸」的存废 | 核心判断 | 保留但边缘化（被「求放心」消解） | 删除（被「刑」替代） | 不需要（被「三世因果」覆盖） |

### 「幸」的衰退链

```
孔子：「幸」= 核心判断（概率论——道德宇宙不是必然报应的）
  │
  ▼ 消解机制：性善论需要报应担保→「求放心」把罔者转成失者
孟子：「幸」= 边缘词（被「求放心」「浩然之气」消解）
  │
  ▼ 消解机制：性恶论不允许侥幸者存在→不直者该受刑
荀子：「幸」= 删除（被「刑法」替代——不直者刑，无可免）
  │
  ▼ 消解机制：三世因果覆盖一切例外→没有例外，只有延期
佛学：「幸」= 不需要（被「三世因果」覆盖——时候未到）
```

### 「君子固穷」四家答案

| 家派 | 答案 | 哲学类型 |
|------|------|---------|
| 孔子 | 「固穷」——穷就穷，君子不滥。没有解释，只是扛着 | 存在论——接受现实，不给解释 |
| 孟子 | 「天将降大任于是人也」——穷是上天在锻炼你 | 目的论——穷有神圣目的 |
| 荀子 | 人之性恶——穷是因为礼法不彰，需要更强的礼法 | 制度论——穷是制度失败，可修复 |
| 佛学 | 前世业报——穷是前世恶业的果报 | 因果论——穷是可解释的 |

### 三条收敛线

1. **「幸」的衰退史**：每一个后来者都比孔子更需要报应的必然性。孟子需要它支撑性善论，荀子需要它支撑礼法，佛学需要它支撑因果——只有孔子不需要担保。

2. **「解释」的递增曲线**：从孔子（不给解释）→孟子（目的论解释）→荀子（制度论解释）→佛学（因果论解释），解释的完备性越高，孔子的硬度越被稀释。

3. **6.14→6.17 的后世分化**：孔子的四章「隐论证」在后世分裂为四条路线——孟子选质（性善）、荀子选文（礼法）、佛学选彼岸（三世）、孔子本人选「幸」（不需要担保）。

## 关键原则

1. **不强行比较**：若关键词在后世学派中无明确对应论述，标注「[该学派无直接对应]」，不强行拉郎配
2. **不评价优劣**：不判断哪家「对」——只追踪概念如何被处理（升级/删改/置换）
3. **须有原文依据**：孟荀引用须有原文出处（如「告子上」「性恶篇」），佛学引用须标注来源（如程树德「发明」板块提及）
4. **回到本章**：跨学派分析的终点永远是本章——每一条收敛线必须回到6.17的核心判断
