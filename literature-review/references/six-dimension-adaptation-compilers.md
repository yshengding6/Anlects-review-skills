# 六维解剖的编纂者适配

## 问题

`anlects-review` 的六维解剖原始设计针对「注疏者」——提供自己解释判断的学者（皇侃、邢昺、朱熹、戴震、刘宝楠）。当材料遍历清单中出现「集释者/编纂者」（如程树德《论语集释》）时，六维解剖的六个维度无法直接套用——编纂者不提供自己的释义，其「解释立场」不在对原文的直接释义中。

## 适配规则

### 分析对象切换

| 原始对象 | 适配后对象 |
|---------|-----------|
| 注疏者的解释立场 | 编纂者的材料分类方法及其透露的学术立场 |
| 注疏者对原文的释义 | 编纂者的板块设计（考异/音读/考证/集解/唐以前古注/集注/发明） |
| 注疏者的概念操作 | 编纂者的材料取舍逻辑（收录什么、排除什么、排列顺序） |
| 注疏者的方法路径 | 编纂者偶尔插入的按语（如程树德「不成文」判断） |

### 六维度对应调整

| 维度 | 原始 | 编纂者适配 |
|------|------|----------|
| 1. 文本解释 | 注疏者对原文的释义 | 编纂者通过板块命名预设的解释层级 |
| 2. 方法论 | 训诂/义理/考据/玄学 | 材料分类学（七板块设计的认识论预设） |
| 3. 概念重构 | 对原文概念的重新定义 | 「发明」板块的创建——将「应用」从「解释」中分离 |
| 4. 立场假设 | 预设的政治/哲学立场 | 板块分类中隐含的学术等级秩序 |
| 5. 隐含前提 | 默认接受但未声明的预设 | 按语中透露的校勘立场（如程树德倾向翟灏、批评皇本） |
| 6. 时代动机 | 解释在历史语境中的功能 | 集大成式注疏在注疏史末期的位置——传统形态的最后一次完整呈现 |

### 「发明」板块的独特价值

程树德独创的「发明」板块（收录后世一切义理发挥、政治应用、叙事类比）是传统注疏史上此前不存在的分类。在六维解剖中须重点分析：

1. **分离功能**：「发明」将「对原文的释义」（集注）与「借原文的发挥」（发明）强制分离——刘宝楠《正义》中两者混在同一叙述流中的传统被打破
2. **材料的隐性评价**：哪些材料入「发明」而非「考证」或「集注」——这一分类本身就是编纂者对材料性质的判断
3. **与传统注疏的对比**：将此分类与刘宝楠《正义》的行文结构对比，观察材料组织方式的变化如何影响解读

## 注意事项

1. 编纂者的解剖应与同章其他注疏者的解剖**分开进行**，不可将编纂者混入「他还提供了某某注疏」的松散描述中
2. 编纂者板块中收录的新独立立场（如程树德「发明」中的李颙、宦懋庸）须在材料遍历清单中**列为独立项**，逐家进行完整六维解剖
3. 编纂者解剖完成后，应标注「编纂框架解剖完毕，以下为编纂者收录的新增独立立场解剖」
