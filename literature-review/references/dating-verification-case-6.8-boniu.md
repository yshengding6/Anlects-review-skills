# 6.8 伯牛章 — 年代校验与生平补全案例

> 演示「外部生平检索 + 传记时间线交叉验算」如何改变章节解读方向。

## 初始状态

docx 注疏汇编提供的信息：
- 伯牛=冉耕，鲁人（马融、《史记》）
- 少孔子七岁（《圣门志》，刘宝楠注"不审何据"）
- 有恶疾（包咸、《淮南子》"伯牛为厉"）
- 卒年：无记载

**年代校验初判**：卒年不详→标注[缺失]，跳过。

## 用户追问后的深度检索

用户要求"交代清楚伯牛的简历，伯牛生病到底是什么时候？是年轻还是中年或者是老年？"

### 百度百科检索

搜索"冉耕/冉伯牛"百度百科，发现 docx 中未记载的关键信息：

1. **任职履历**："孔子对冉子十分器重，其任鲁国司寇时，冉子曾为中都宰。后，冉子得了不治之症，孔子亲自前去探望。"
2. **家族关系**："冉离生三子：冉耕（字伯牛）、冉雍（字仲弓）、冉求（字子有）"
3. **死亡定性**："因恶疾早逝"

### 年龄推算

- 孔子生 BC 551
- 伯牛生约 BC 544（少孔子七岁）
- 孔子任鲁司寇：BC 500-497（51-55岁）
- 伯牛任中都宰：同期，44-48岁
- 伯牛得病：司寇任后（BC 497后），48-55岁

### 传记时间线交叉验算

冉求生约 BC 522（少孔子29岁），伯牛比冉求大约22岁。
→ 若伯牛死于48-55岁，冉求此时25-33岁→**已成年出仕**。

此验算推翻了初稿中"他死的时候，两个弟弟的人生还没分叉"的表述。

## 结论

伯牛死于中年（约50岁上下），非颜渊式夭折（约40岁），非寿终正寝。

→ "命矣夫"的语义从"痛惜夭折"校准为"中年折断的沉重接受"
→ 与颜渊"天丧予"的措辞差异获得了解释（中年 vs 壮年夭折）
→ 冉求已成年→"孔门三杰"的后续命运对比不依赖"分叉"叙事

## 方法论教训

1. docx 注疏汇编中不包含完整传记信息——年代校验不能仅限注疏文本
2. 即使所有注家集体沉默于某人的卒年，仍可通过外部来源（百度百科）+ 时间线推算获得有价值的推论
3. 涉及多人关系时必须做交叉验算——"还没/尚未"的判断需要数学支撑
4. 百度百科信息应标注"[后世辑佚·出处待核]"，不得混入[实证]级
